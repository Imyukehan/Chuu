# Chuu 交互方案

2026-09-19。用户已确认开始第一版实现；以下保留设计背景和后续范围，不代表所有验收场景都已完成。

## 第一版范围

- 四个主选项卡；鼠标页中切换板载按键和全局快捷操作，保留原有应用规则。
- 连接浮窗采用非激活 NSPanel 和系统玻璃材质，约 5 秒消失；通用页提供预览。
- 20% 低电量通知；系统成功接收通知后才记录去重状态，25% 恢复。
- 热插拔触发重新读取。已在线过的 2.4 GHz 鼠标若接收器始终存在，后续无线超时及恢复不弹连接提示。当前协议无法可靠区分省电休眠与电源开关，不声称即时开机检测。
- 睡眠、屏幕关闭、锁屏、屏保和切换用户时抑制浮窗；恢复后重新建立基线。
- 普通 HID 鼠标显示通用符号与实际传输方式；无电量协议时显示不可用。部分仅以 Receiver 命名的未知接收器暂不展示，避免误报在线。

索引注明来源为 Logitech Options+ / G HUB 运行时资源。其代码开源许可不等于厂商产品素材再分发许可。

## 页面结构

建议顶栏收敛为：**鼠标 / 滚动 / 应用 / 通用**。

鼠标页仍以大鼠标图为中心，左上设备名和连接状态，右上电量。将当前独立“按键”页收进右侧设置区，使用分段控件区分：

- **快捷操作**：现有 Mos 的系统动作和快捷键规则。当前规则是全局的，不能因为选了某只鼠标就暗示它变成按设备生效。
- **板载按键**：G502 X PLUS 的硬件按键映射。保留“应用”按钮、写入前备份、读回校验。仅支持的设备显示。

普通鼠标使用原创通用外观和相同的操作入口；不能读电量就不编造百分比，也不展示 RGB、板载写入等不可用控制。发现设备与支持电量协议分开实现，不能把接收器存在当成鼠标在线。键盘的虚拟鼠标接口和内置触控板也应过滤。

界面不添加大段说明，详细差异放到悬停提示和帮助文档。优先沿用系统控件，让玻璃效果服务于选项卡、分段选择和浮窗。

## 连接提示

建议首次连接或明确重连时，在当前屏幕底部中央显示小浮窗：鼠标图、名称、连接方式、电量；约 5 秒后消失，可手动关闭。

- 用公开 [NSPanel](https://developer.apple.com/documentation/appkit/nspanel) API 和系统材质实现 Chuu 自己的提示，不调用苹果私有 AirPods 面板。
- 不抢键盘焦点，不激活主窗口，不点亮屏幕。锁屏、睡眠、快速切换用户期间不弹；解锁后不补弹旧消息。
- 启动时只建立设备基线，避免开机所有设备一起弹出。
- 接收器热插拔触发读取；2.4 GHz 鼠标的开关机还需要协议事件或轮询。现有 30 秒电量轮询不等于即时连接检测。
- 单次读取失败不算断开；真正重连合并去重。不能把鼠标日常省电唤醒变成每次都弹窗。
- “通用”中提供连接提示开关及预览入口。

## 低电量提醒

建议使用系统 UserNotifications：默认阈值 20%，每个充电周期提醒一次，充到 25% 以上再重新启用提醒。后续再考虑可调阈值和 10% 的二次提醒。

- 用户开启时申请 [通知权限](https://developer.apple.com/documentation/usernotifications/asking-permission-to-use-notifications)，遵守系统通知与专注模式设置。
- 离线、过期、无电量读数或设备明确报告正在充电时不通知。
- 去重状态跨 App 重启保存；通知失败或权限变化要能恢复，不能悄悄丢掉后续提醒。
- 点击通知打开对应设备。小组件只显示状态，后台 App 负责采样和提醒。
- 第三方 Qi 底座可能不报告充电，不能靠猜测功率或看到底座来判定正在充电。

## 后续优先级

1. 先确认上述页面合并与提醒规则，再做最小实现和真实重连验证。
2. 配置导出、导入与回滚，包含按应用规则。
3. 指针速度、加速度和 DPI：先区分系统设置与板载设置，再按设备验证。
4. 按住侧键的拖动、滚动手势，以及更清楚的按键录制反馈。
5. 更多设备适配和能力清单；暂不加入账号、云端同步、跨电脑控制或宏市场。

验收需要覆盖：连接与断开、读数超时、休眠唤醒、锁屏不亮屏、通知授权与拒绝、多设备、低电量去重、现有应用规则不丢失。
