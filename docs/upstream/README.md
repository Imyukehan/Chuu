# Upstream Archive

`readmes/` preserves the original Mos translations as historical material, not documentation for Chuu. Their original relative links refer to the upstream repository layout. The upstream website, release notes and release scripts elsewhere in this repository are also historical; do not use them to build or publish Chuu.

For current documentation use the [English README](../../README.md), [Chinese README](../../README.zh-CN.md), and [build guide](../build.md).

The obsolete Mos Xcode project and test plans were removed from the working tree during the Chuu project rename. They remain recoverable from Git history. Upstream attribution and license remain intact.
