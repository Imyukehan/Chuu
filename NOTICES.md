Chuu is a modified, noncommercial fork of [Mos by Caldis](https://github.com/Caldis/Mos).
The upstream [CC BY-NC 4.0 license](LICENSE), author attribution and Git history are retained.
Changes include the native Chuu window and branding, mouse battery adapters, onboard-profile controls and WidgetKit extension.
Upstream documentation, website and release assets that remain in this repository describe Mos, not a Chuu release.

## Chuu Artwork

The Chuu Icon Composer layers and status-item symbol were created for this project.
They do not use the OpenLogi or Logitech app icons.

`GenericMouse` is an AI-generated, unbranded illustration created for Chuu,
inspired by the white touch-mouse form of Magic Mouse. It is a visual placeholder,
not an Apple-supplied asset or a claim that the connected device is an Apple mouse.
