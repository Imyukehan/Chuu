# Chuu 0.1.7

## 更新内容

- Developer ID 正式签名及 Apple 公证，App 和电量小组件使用同一开发者团队。
- 接入 GitHub 自动更新，无需登录或令牌；更新源和安装包均验证签名。
- 运行期间每 12 小时自动检查，可在“通用”关闭；安装前会提示确认，菜单支持立即检查。
- 包含 0.1.5 的键盘接收器过滤和连接胶囊优化。
- 保留现有鼠标改键、连点、RGB 和按应用设置。

仅提供 Apple Silicon（M 系列芯片）版本，支持 macOS 14 及以上。

第一次从旧临时签名版本安装时，请按引导恢复辅助功能和输入监控。旧版尚未接入更新源，需要手动安装本版一次，后续由 App 检查更新。参见[权限说明](https://github.com/Imyukehan/Chuu/blob/main/docs/build.md#first-launch-permissions)。

## Changes

- Developer ID signed and Apple notarized, with matching app/widget team signing.
- Public GitHub updates through Sparkle, with signed feeds and archives. No account or access token required.
- Automatic checks every 12 hours while running, a General setting to disable them, and manual checks in the Chuu menu. Installation asks for confirmation.
- Includes the 0.1.5 keyboard-receiver filter and connection-capsule refinements.
- Preserves mouse mappings, hold-to-click, RGB and per-app settings.

Apple Silicon only; requires macOS 14 or later.

When replacing an older ad-hoc build, complete Accessibility and Input Monitoring setup. Older builds without the update feed need one manual installation of this version before future in-app updates. See [permission setup](https://github.com/Imyukehan/Chuu/blob/main/docs/build.md#first-launch-permissions).
