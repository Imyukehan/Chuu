Chuu 0.1.7

  • Developer ID 正式签名及 Apple 公证，App 和电量小组件使用同一开发者团队。
  • 接入 GitHub 自动更新，无需登录或令牌；更新源和安装包均验证签名。
  • 运行期间每 12 小时自动检查，可在“通用”关闭；安装前提示确认，菜单支持立即检查。
  • 包含 0.1.5 的键盘接收器过滤和连接胶囊优化。
  • 保留鼠标改键、连点、RGB 和按应用设置。

Apple Silicon，macOS 14 及以上。第一次替换旧临时签名版时，请按引导恢复辅助功能和输入监控。未接入更新源的旧版需手动安装一次。

Changes

Apple Silicon, macOS 14+. Older ad-hoc builds may need permission setup and one manual installation to join this update channel.
